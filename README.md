# Open Science MCP (Netlify 版)

一键部署到 Netlify：

## 部署步骤

1. Fork 本仓库
2. 访问 https://app.netlify.com/start
3. GitHub 登录，选择仓库
4. 直接 Deploy，不需要额外配置

部署后 MCP 端点：`https://your-site.netlify.app/mcp`

## 扣子注册

- **名称**: `open-science`
- **URL**: `https://your-site.netlify.app/mcp`
- **传输模式**: Streamable HTTP

## 工具

8 个科研工具：OpenAlex (3个)、arXiv、PubMed、DOI、Zenodo、CrossRef
