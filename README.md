# Open Science MCP (Vercel 部署版)

## 一键部署到 Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FHitchcock-Traveller%2Fopen-science-mcp%2Ftree%2Fvercel)

### 手动部署

1. Fork 此仓库
2. 访问 https://vercel.com/new
3. 选择仓库，Framework 选 "Other"
4. 直接 Deploy

部署后你的 MCP 端点：`https://your-app.vercel.app/api/mcp`

## 在扣子中注册

- **名称**: `open-science`
- **URL**: `https://your-app.vercel.app/api/mcp`
- **传输模式**: Streamable HTTP
